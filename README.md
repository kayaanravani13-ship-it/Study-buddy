# Study Buddy — merged free-first app

Includes dashboard, editable default list of 11 school subjects, subject-linked tasks, due dates, completion percentage, local notes, mini quiz, 25-minute focus timer, streak counter, textbook-resource search links, notification permission request, PWA installation support, and offline caching.

## Run on Android
Extract the ZIP and host the files on an HTTPS static host such as GitHub Pages, Netlify, or Cloudflare Pages. Open the HTTPS URL in Chrome on Android and use Install/Add to Home screen. Offline support works after the first successful load. Notifications require browser permission and support.

## Notes
Data is stored locally in the browser on this device. Clearing browser data may erase it. This is a PWA, not a Play Store APK. Play Store publishing requires further packaging, testing, and applicable account requirements; a minor should have an eligible adult manage the developer account.

This combined build recreates the earlier-described features; the exact earlier ZIP was not available here for a file-by-file merge.
